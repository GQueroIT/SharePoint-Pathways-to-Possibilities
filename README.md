# SharePoint – Pathways to Possibilities

> Building a complete SharePoint-based event management solution for the **Pathways to Possibilities: Launch Your Future Summit** at **SUNY Empire State University**.

---

## Overview

This repository documents the planning, design, implementation, testing, and documentation of a SharePoint-based event management solution developed in support of the **Pathways to Possibilities: Launch Your Future Summit**.

This project captures the complete lifecycle of delivering a business solution—from gathering requirements and creating participant forms to implementing SharePoint components and preparing documentation for stakeholder review.

Every deliverable is documented as an individual project, allowing the complete implementation process to be understood, recreated, and maintained over time.

---

## Project Objectives

The primary objectives of this project are to:

- Design a user-friendly event management solution.
- Build participant forms using Submittable.
- Develop SharePoint components to support the event.
- Document every implementation step.
- Create reusable administrative documentation.
- Deliver an organized and maintainable solution for Career Services.

This repository documents more than the finished solution.
