# SharePoint – Pathways to Possibilities

> Repository documenting the planning, implementation, and administration of the **Pathways to Possibilities: Launch Your Future Summit** project for **Career Services at SUNY Empire State University**.

---

# Overview

This repository documents the complete implementation of the **Pathways to Possibilities: Launch Your Future Summit** project.

The project supports Career Services by designing, implementing, and documenting the digital solutions used to manage event participation, presenter submissions, volunteer recruitment, student engagement, and future SharePoint resources.

Rather than only preserving the finished products, this repository documents the complete process used to build each solution. Every deliverable includes the planning, implementation decisions, testing, screenshots, and supporting documentation needed for another administrator to recreate the solution from start to finish.

---

# Business Need

Career Services required a centralized collection of digital solutions to support planning and administration of the Pathways to Possibilities event.

The project includes participant-facing forms developed in Submittable as well as the supporting SharePoint resources that will organize event information, documentation, and administrative processes.

The long-term objective is to provide Career Services with solutions that are easy to maintain, scalable for future events, and fully documented for future staff.

---

# Project Objectives

The objectives of this repository are to:

- Design user-friendly digital solutions for event participants.
- Develop standardized forms using Submittable.
- Build supporting SharePoint resources.
- Apply consistent event branding across all deliverables.
- Document every implementation from planning through completion.
- Produce documentation that allows another administrator to recreate the work.
