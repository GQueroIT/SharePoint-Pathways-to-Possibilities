# Testing

## Objective

Verify that the Image and Visual Boards Form functions correctly, collects the required information, and provides a consistent user experience.

## Test Results

### Form Layout

- Verified all sections appear in the intended order.
- Confirmed headings and instructional text display correctly.
- Confirmed official event branding appears in the welcome section.

**Status:** Passed

---

### Required Fields

Verified all required fields prevent submission when left blank.

Required fields tested:

- Full Name
- Email Address
- Role
- Visual Board Title
- Category
- Brief Description
- Visual Board Upload
- Permission Agreements

**Status:** Passed

---

### Optional Fields

Verified optional fields can be left blank without preventing submission.

Optional fields tested:

- Phone Number
- Organization / School / Department
- Intended Audience
- Supporting Files
- Multimedia Description
- Special Display Requirements

**Status:** Passed

---

### Conditional Logic

Verified the multimedia description field only appears when the participant selects **Yes** for multimedia components.

**Status:** Passed

---

### File Uploads

Verified the primary visual board upload field accepts supported file types.

Verified supporting files can be uploaded when provided.

**Status:** Passed

---

### Permissions

Verified both required permission acknowledgements must be accepted before submission.

**Status:** Passed

---

### Branding Review

Confirmed the event logo, welcome message, and introductory information display consistently with the other participant-facing forms created for the Pathways to Possibilities project.

**Status:** Passed

---

## Overall Result

The Image and Visual Boards Form successfully collects submission information, uploaded materials, display requirements, and participant permissions while maintaining a consistent design and user experience across the Pathways to Possibilities event registration system.
