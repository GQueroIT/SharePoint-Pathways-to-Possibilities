# Implementation Guide

## Objective

Create a simple submission experience for contributors who wish to display an image or visual board during the Pathways to Possibilities: Launch Your Future Summit.

---

## Step 1

Create a new form in Submittable.

Name:

Image and Visual Boards Form

---

## Step 2

Create the welcome section.

Include:

- Event logo
- Summit title
- Welcome message
- Event dates
- Brief description

---

## Step 3

Create the Submitter Information section.

Fields:

- Full Name
- Email Address
- Phone Number
- Organization / School / Department
- Role

---

## Step 4

Create the Visual Board Information section.

Fields:

- Visual Board Title
- Category
- Brief Description
- Intended Audience

---

## Step 5

Create the Uploads section.

Fields:

- Upload Visual Board
- Supporting Files

Supported formats:

- PDF
- PowerPoint
- PNG
- JPEG

---

## Step 6

Create the Display Information section.

Fields:

- Multimedia Included
- Multimedia Description
- Special Display Requirements

---

## Step 7

Create the Permissions section.

Include agreement checkboxes for:

- Permission to display submitted work
- Permission for photography and promotional use

---

## Step 8

Customize the form.

Completed improvements:

- Added official Pathways to Possibilities branding
- Added event logo
- Improved visual consistency across all event forms
- Simplified user instructions
- Reduced unnecessary required fields

---

## Result

The completed form provides a consistent and user-friendly experience while collecting all information required to display visual board submissions during the summit.
