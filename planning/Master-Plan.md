# Master Plan

# Project Overview

The **Pathways to Possibilities** project was developed to support Career Services at SUNY Empire State University by creating a collection of digital solutions for the **Pathways to Possibilities: Launch Your Future Summit**.

The project consists of participant-facing forms developed in Submittable, supporting SharePoint resources, and documentation that captures every stage of implementation.

Rather than documenting only the finished products, this repository documents the complete process used to plan, build, test, review, and maintain each solution.

---

# Project Goals

The primary goals of this project are to:

- Build user-friendly digital solutions for event participants.
- Create consistent experiences across all event forms.
- Support Career Services with organized and maintainable solutions.
- Apply approved committee branding throughout the project.
- Document every implementation from beginning to completion.
- Produce documentation that allows another administrator to recreate each solution.

---

# Project Methodology

Each deliverable follows the same development process.

```text
Business Need
      │
      ▼
Planning
      │
      ▼
Design
      │
      ▼
Implementation
      │
      ▼
Testing
      │
      ▼
Documentation
      │
      ▼
Committee Review
      │
      ▼
Revision
      │
      ▼
Production
```

This workflow ensures every solution is developed consistently while allowing committee feedback throughout the project.

# Deliverables

Current project deliverables include:

- Save the Date Interest Form
- Event Registration Form
- Call for Presentations
- Student Virtual Poster Session
- Image & Visual Boards
- Committee Volunteer Form
- Toastmasters Form
- Future SharePoint Components

Each deliverable is documented independently using a consistent documentation structure.

---

# Documentation Standard

Each completed deliverable contains:

- README.md
- Planning.md
- Decisions.md
- Implementation.md
- Testing.md
- Screenshots

This documentation is intended to provide enough detail for another administrator to recreate the solution without relying on the original author.

---

# Branding Standard

The committee approved the official **Pathways to Possibilities** logo as the project's branding standard.

All future forms, SharePoint resources, screenshots, and documentation will use the approved branding to maintain consistency throughout the project.

---

# Project Success Criteria

The project will be considered complete when:

- All committee-requested forms have been implemented.
- SharePoint components have been completed.
- Documentation has been finalized.
- Administrative guides have been completed.
- Career Services has a maintainable solution that can be supported by future staff.
