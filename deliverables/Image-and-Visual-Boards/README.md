# Image and Visual Boards Form

## Overview

The Image and Visual Boards Form allows participants to submit digital visual displays for inclusion in the Pathways to Possibilities: Launch Your Future Summit.

This form streamlines the collection of visual presentations by gathering submitter information, board details, uploaded files, display requirements, and permissions in a single submission.

---

## Purpose

The form was designed to:

- Collect digital visual board submissions
- Standardize information collected from contributors
- Gather display requirements before the event
- Collect all supporting files in one location
- Obtain permission to display submitted work during the summit

---

## Features

- Submitter Information
- Visual Board Information
- File Uploads
- Multimedia Requirements
- Display Requirements
- Permission Agreements
